## Description

This video shows you how to use the CrewAI CLI for building teams of virtual agents. The CrewAI CLI is the recommended way to build crews of agents in the CrewAI ecosystem. In this DEMO we build an award-winning duo of musicians for helping us create hit songs. The only required software for following along is Docker and VSCode. Also included in the DEMO is how to set up your crews for monitoring using AgentOps. Enjoy!
